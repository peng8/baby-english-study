# 幼儿英语启蒙网页 - PRD
## 一、产品概述
### 1.1 目标用户
- 儿童：3‑4岁零基础幼儿，平板触摸操作
- 家长：程序员家长，用于家庭启蒙，辅助孩子英语磨耳朵
### 1.2 产品约束
1. 纯前端本地网页，不需要后端服务；
2. 适配平板，大按钮、大图片，触摸友好；
3. **禁止出现：字母认读、拼写、默写、分数、答错惩罚机制**；
4. 仅做启蒙辅助，核心学习场景要落地到现实亲子互动；
5. 视频不内置版权资源，只保存标题、封面，跳转外部链接；
6. 内置屏幕时长温馨提示。
### 1.3 核心目标
- 阶段目标：熟悉英文语音语调，建立英语好感；
- 能力目标：听懂高频单词、简单指令短句，不强迫开口跟读。

## 二、整体功能模块
1. 首页（阶段导航、学习提示）
2. 闪卡学习模块
3. 游戏中心
4. 儿歌&视频资源库
5. 复习模块
6. 家长专区（儿童模式隐藏）

### 2.1 首页
- 展示4个学习阶段入口，可视化简单学习进度
- 醒目提示：每日建议使用5‑10分钟
- 跳转入口：闪卡｜游戏中心｜儿歌库｜家长专区

### 2.2 闪卡学习模块
功能：
1. 按分类展示单词卡片，图片+英文+中文释义
2. 点击卡片播放美式发音，语速调慢适合幼儿
3. 支持自动轮播朗读模式
4. 单词收藏功能，收藏孩子感兴趣单词
5. 可按阶段/分类筛选词汇

### 2.3 游戏中心
> 全部游戏：答错无惩罚，只有正向鼓励动画，不打分
1. 听音识图：播放单词发音，点击匹配对应图片
2. 图片配对游戏：图‑图配对，不使用文字配对
3. 分类小游戏：把图片拖拽归类到对应组别
4. 听指令做动作：播放动词语音，看对应动作画面
5. 情景寻宝游戏：播放问句，在画面中找到目标物品

### 2.4 儿歌&视频资源库
字段：歌名、封面图、简介、外部跳转链接
只做跳转，不存储音视频文件；记录已浏览记录。

### 2.5 复习模块
1. 按阶段随机抽卡复习
2. 支持复习收藏单词
3. 复习闯关模式，无分数，只有鼓励动画

### 2.6 家长专区（儿童模式默认隐藏）
1. 已学习单词统计
2. 每周启蒙计划
3. 亲子拓展任务清单
4. 启蒙避坑提醒
    - 不强迫跟读；
    - 不做默写练习；
    - 控制屏幕时间；
    - 网页只是辅助，现实实物互动优先。

## 四、UI/交互要求
1. 配色：柔和童趣，低饱和度，避免刺眼；
2. 控件：大尺寸按钮、卡片，适配手指触摸；
3. 语音：使用美式发音，语速降低 0.8‑0.85；
4. 动画：答对只有正向鼓励，无失败弹窗；
5. 响应式：优先平板横屏、竖屏兼容。

## 五、重要产品禁忌（必须写入文档）
1. 3‑4岁阶段**不出现26个字母**，5岁以后再引入；
2. 不做默写、认读考核；
3. 不设置分数、排名；
4. 网页只是辅助启蒙，现实生活互动优先级高于屏幕学习。
